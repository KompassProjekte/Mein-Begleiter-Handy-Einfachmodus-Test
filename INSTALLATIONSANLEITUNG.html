Getrennte Testausgabe: Nur mit erfundenen Testdaten verwenden. Vor einer Aktualisierung eine verschlüsselte vollständige Sicherung erstellen.

Startadresse

https://kompassprojekte.github.io/Mein-Begleiter-Handy-Einfachmodus-Test/

Android

  1. Die Adresse in Firefox oder Chrome öffnen.
  2. Den vom Browser angebotenen Punkt „App installieren“ wählen.
  3. Nach der Installation aus dem Symbol „MB + Neu“ starten.
  4. Beim ersten Start Einfachmodus oder vollständige Ansicht auswählen.

Aktualisierung

  1. Verschlüsselte vollständige Sicherung erstellen und Kennwort sicher notieren.
  2. Wenn die App eine neue Version meldet, „Jetzt aktualisieren“ wählen.
  3. Version 1.8.6.1 und den Knopf „+ Neu“ kontrollieren.

Datenschutz

Keine Werbung, Analyse, Benutzerkonten oder automatische Cloud-Synchronisation. Sicherungsdateien entstehen nur durch eine bewusste Benutzeraktion.
