Android

  1. Die Adresse in Firefox oder Chrome öffnen.
  2. Den vom Browser angebotenen Punkt „App installieren“ wählen.
  3. Nach der Installation aus dem Symbol „MB Einfach“ starten.
  4. Beim ersten Start Einfache Ansicht oder vollständige Ansicht auswählen.

PC

Die Adresse im Browser öffnen. Auf einem PC wird die vollständige Ansicht empfohlen; der Einfache Ansicht bleibt auswählbar.

Aktualisierung

Vor einer Aktualisierung eine sichere vollständige Sicherung erstellen. Wird eine neue Ausgabe gemeldet, „Jetzt aktualisieren“ wählen.

Datenschutz

Keine Werbung, Analyse, Benutzerkonten oder automatische Cloud-Synchronisation. Sicherungsdateien entstehen nur durch eine bewusste Benutzeraktion.
